# AI Policy

## Purpose

This document explains how AI tools are allowed to be used in Project B.

## Allowed Use of AI

AI tools may be used for the following purposes:

- Explaining programming concepts.
- Helping understand C++ syntax.
- Suggesting project structure.
- Drafting documentation.
- Helping debug error messages.
- Suggesting test cases.
- Improving code comments.
- Improving README content.

## Not Allowed Use of AI

AI tools should not be used to:

- Submit code without understanding it.
- Copy generated code without reviewing it.
- Hide the use of AI assistance.
- Replace the student's own learning process.
- Submit work that the student cannot explain.

## Student Responsibility

The student is responsible for:

- Reading and understanding all generated content.
- Testing the program before submission.
- Checking that the code works correctly.
- Making sure the project follows course requirements.
- Editing AI-assisted content when necessary.

## Disclosure

If AI tools are used during the project, the usage should be recorded in `AI_USAGE.md`.

## Summary

AI tools may be used as learning and drafting assistants, but the final project must be reviewed, tested, and understood by the student.
