# 00 Intended Use

## Project Name

ProjectB - CSV Student Query Engine

## Purpose

This project is a simple C++ command-line program that reads student data from a CSV file and allows users to search or display student records.

The purpose of this project is to practice basic software development workflow, including:

- Planning requirements
- Designing program structure
- Writing C++ source code
- Testing with sample CSV files
- Documenting known issues
- Using GitHub and Jira for project tracking

## Intended Users

The intended users of this program are:

- Students learning C++ file processing
- Developers practicing CSV parsing
- Instructors who want to evaluate basic software engineering workflow
- Users who need a small command-line tool to inspect student records

## Intended Environment

This program is intended to run in a terminal environment.

Recommended environment:

- Operating System: Windows, Linux, or macOS
- Compiler: g++ or compatible C++ compiler
- Language Standard: C++17 or newer

## Main Use Case

The user provides a CSV file containing student information. The program loads the file, parses the data, and allows the user to perform simple queries.

Example CSV format:

```csv
id,name,major,year
1101,Alice Chen,Computer Science,3
1102,Bob Lin,Information Management,2
1103,Cathy Wang,Computer Science,1
